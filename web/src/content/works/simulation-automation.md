## 能力概述

面向批量工况计算和参数迭代，利用 AI Agent 与工程脚本组织仿真流程自动化：

- 在工具之间传递模型参数与工况配置。
- 调度计算任务并跟踪执行状态。
- 自动提取、整理和分析仿真结果。
- 通过标准化脚本降低重复操作成本，提高参数迭代效率。

工程工具包括 VS Code、Docker、Git、LangChain、RAG、Codex 与 Claude Code，并具备 Agent 应用和自动化工作流开发经验。
