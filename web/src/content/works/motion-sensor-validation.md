## 岗位方向

目标岗位为**兼职运动传感器算法验证工程师**。力学、传感信号处理与 AI 算法的交叉背景，可用于运动状态数据分析、算法实现、模型验证和异常排查。

## 算法与验证能力

- 熟悉 TensorFlow 与 PyTorch，具备机器学习和深度学习模型的构建、训练、调参及评估经验。
- 熟悉 PINN、CNN、LSTM、GNN，可根据时序、空间关系和物理约束选择模型结构。
- 使用 NumPy、Scikit-learn 与 Matplotlib 开展数据处理、基线建模、指标评估和结果可视化。
- 使用 MATLAB 与 LabVIEW 处理振动/传感信号，并结合结构动力学仿真分析结果。

## 场景理解

双板与单板滑雪爱好者，对速度变化、姿态、冲击、转弯和振动等运动传感场景具备直接体验，可从实际使用者视角理解数据质量与算法表现。
